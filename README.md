An original top-down 2D open-world crime game, built for make.fun's **gta6-01** bounty. Explore the city of Solmaris on foot or by car: steal vehicles, outrun a five-star wanted system with police pursuit, fight with melee or a pistol, and work a five-mission story chain for fixer Mara Voss. Traffic AI, pedestrians, a HUD with minimap, pause and start screens, a localStorage save, and synthesized WebAudio sound — all in vanilla JavaScript with no build step and no network loads.

## Play it

Open `game/index.html` in a browser, or serve the folder:

```sh
node serve.ts
```

The entrypoint `main.ts` copies `game/` and `screenshots/` to the output directory and writes the dossier the bounty grades.
